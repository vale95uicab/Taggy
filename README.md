# TAGGY 🐾
Sitio web estático (HTML + CSS + JS). Para verlo en línea con GitHub Pages:

1. Crea un repositorio nuevo en GitHub (público).
2. Sube TODOS los archivos de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz).
3. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/ (root)** y guarda.
4. Espera 1-2 minutos: tu sitio quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Nota: en GitHub los nombres de archivo distinguen mayúsculas y no deben llevar espacios.
